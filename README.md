# 농산물 자동 품질 판정 및 선별 시스템

AI Hub 농산물 품질(QC) 이미지를 이용해 품질 등급을 판정하고, 판정 결과를 선별 흐름으로 연결하는 1개월 팀 프로젝트입니다.

## MVP 범위
- 우선 품목: 사과 1종
- 확장 후보: 감귤
- 출력: 특/상/보통 등급, 신뢰도, 선별 목적지
- 자동화: 판정 기록, 저신뢰 검수 분리, 등급별 선별 신호 시뮬레이션
- 제외: 설비 고장예지와 설비보전

## 폴더 역할
| 폴더 | 역할 |
|---|---|
| `docs/` | 요구사항, 데이터 명세, 아키텍처, WBS, 프로젝트 계획 문서 |
| `data/raw/` | AI Hub에서 받은 원본 이미지와 라벨. 원본을 수정하지 않음 |
| `data/processed/` | 학습용으로 정리·변환·분할한 데이터 |
| `notebooks/` | 데이터 탐색, 품목·등급 분포 확인, 모델 실험 기록 |
| `src/data/` | 데이터 읽기, 검증, 전처리, 학습·검증·시험 분할 코드 |
| `src/models/` | 모델 구조와 모델 생성 코드 |
| `src/training/` | 학습, 평가, 실험 실행 코드 |
| `src/inference/` | 저장된 모델을 불러와 새 이미지를 판정하는 코드 |
| `src/api/` | 추론 기능을 외부 화면과 연결할 API 코드 후보 |
| `src/web/` | 이미지 입력과 판정 결과를 보여줄 웹 화면 후보 |
| `tests/` | 데이터 처리와 추론 흐름의 검증 코드 |
| `configs/` | 경로, 품목, 학습값 등 실행 설정 |
| `scripts/` | 데이터 준비, 학습, 실행을 돕는 명령 스크립트 |
| `models/` | 학습된 모델 파일과 체크포인트 |
| `outputs/` | 평가표, 그래프, 예측 결과와 시연 산출물 |

## 현재 상태
기획 단계입니다. 기술 스택, 팀 인원과 역할, 실제 일정, 평가 목표, 하드웨어 연동 범위는 아직 정하지 않았습니다.

## 문서 작성 순서
1. 프로젝트 요구사항
2. 테이블(데이터) 명세서
3. 아키텍처
4. WBS

기초 계획은 `docs/project-plan.md`에서 관리합니다.
