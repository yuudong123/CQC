# 각도 균형 랜덤 12장 샘플링

> 2026-09-23: 사용자 요청으로 후속 6회 실험을 중단했다. 프로젝트 기준 모델은 v2로 유지하며 자동 재개하지 않는다. 아래는 기존 구현·실험 절차 기록이다. 최신 증강 계획은 `docs/wbs/[DM-06] 모델·입력 장수 비교.md`를 따른다.

## 목적

고정된 대표 12장만 반복 학습하는 대신, 동일 사과가 가진 40장 이상의 촬영 이미지에서 epoch마다 다른 12장을 선택해 입력 다양성을 높인다. 이 방식은 사과 그룹 수를 늘리는 것이 아니라 같은 사과 안에서 관측 각도를 바꾸는 학습 증강이다.

기존 v2가 품질 기준을 충족하면 실행하지 않는다. 기준 미달 시 v2에서 선정된 손실·정규화 설정을 그대로 유지하고 샘플링 방식만 비교한다.

## 선택 규칙

1. 프레임을 `top`과 `bottom` 촬영면으로 나눈다.
2. 두 촬영면이 모두 있으면 12장을 6장씩 배분한다.
3. 각 촬영면을 수평각 순서로 정렬하고 6개의 연속 각도 구간으로 나눈다.
4. 각 구간에서 한 장을 무작위 선택한다.
5. 난수는 `seed + epoch + group_no`의 SHA-256 값으로 생성한다.
6. 같은 seed·epoch·사과는 항상 같은 12장을 반환하고, epoch가 바뀌면 조합이 바뀐다.
7. 한 촬영면만 있으면 해당 촬영면 전체 각도에서 12장을 선택한다.
8. 12장 미만 그룹은 모든 프레임을 사용하고 부족분을 마스킹한다.

## 누수 방지

- 하나의 사과에서 생성된 모든 조합은 원래 `group_no`와 fold를 유지한다.
- 랜덤 샘플링은 학습 데이터에만 적용한다.
- Validation·source holdout·Test는 기존 고정 12장 선택을 유지한다.
- 기존 Test 결과는 샘플링 방식이나 epoch 선택에 사용하지 않는다.

## 실제 데이터 사전 검증

- 전체 사과 그룹: 179개
- top·bottom이 모두 있는 40장 그룹은 epoch마다 6장+6장 선택
- 8장 그룹은 8장 사용 후 4슬롯 마스킹
- 16장 단일 촬영면 그룹은 해당 촬영면에서 12장 선택
- seed 42의 1~3 epoch에서 그룹당 서로 다른 프레임은 평균 30.56장, 최소 8장, 최대 36장

따라서 대부분의 40장 이상 사과는 세 epoch 동안 고정 12장보다 넓은 표면을 학습한다. 이것을 독립 사과 3개로 계산하거나 데이터 분할 수를 늘리지는 않는다.

## 후속 실험

v2 보고서에서 선택된 variant와 공통 epoch를 읽어 다음 6회만 실행한다.

- 5-fold Group CV: 5회
- AI Hub 원본 Validation source holdout: 1회

```powershell
python -m data.sampling.experiments
```

위 명령은 기본적으로 계획만 생성한다. 실제 학습은 `--execute`를 명시해야 시작한다. 고정 12장 v2 결과와 각도 균형 랜덤 결과는 품질 Macro F1 평균뿐 아니라 최저 fold, source holdout, M Recall을 함께 비교한다.
