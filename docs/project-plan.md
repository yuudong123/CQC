# 기초 프로젝트 계획

## 1. 프로젝트 개요
AI Hub 농산물 품질(QC) 이미지 데이터를 이용해 농산물 이미지를 특·상·보통 등급으로 판정하고, 결과에 따라 선별 목적지를 정하는 자동화 시스템의 MVP를 구현합니다.

## 2. 우선 범위
- 사과 1개 품목으로 기준선 모델과 전체 흐름을 먼저 완성합니다.
- 감귤 추가는 사과 모델의 데이터 분포와 일정 여유를 확인한 뒤 결정합니다.
- 실제 컨베이어나 제어 장치가 없으면 화면과 로그로 선별 동작을 시뮬레이션합니다.
- 설비 상태 진단, 고장예지, 설비보전 기능은 포함하지 않습니다.

## 3. MVP 흐름
1. 사용자가 사과 이미지를 입력합니다.
2. 모델이 특·상·보통 등급과 신뢰도를 반환합니다.
3. 시스템이 등급별 선별 목적지를 정합니다.
4. 신뢰도가 낮은 결과는 수동 검수 대상으로 표시합니다.
5. 판정 시각과 결과를 기록합니다.

## 4. 4주 계획
| 기간 | 목표 | 주요 결과물 |
|---|---|---|
| 1주차 | 요구사항과 데이터 확인 | 요구사항, 라벨 구조, 품목·등급 분포, 데이터 분할 기준 |
| 2주차 | 기준선 모델 구축 | 재현 가능한 학습 과정, 첫 성능 평가, 오류 사례 |
| 3주차 | 서비스 흐름 연결 | 이미지 입력, 추론, 저신뢰 검수, 선별 시뮬레이션 |
| 4주차 | 통합과 발표 준비 | 최종 데모, 평가 결과, 문서, 발표 자료 내용 |

## 5. 문서 작성 순서
`(서식)프로젝트 요구사항.md`를 먼저 확정하고, `(서식)테이블(데이터) 명세서.md`, `(서식)아키텍처.md`, `(서식)WBS.md` 순서로 구체화합니다.

## 6. 확인할 사항
- 팀 인원과 역할
- 프로젝트 시작일과 발표일
- 사과 단일 품목 확정 여부
- 실제 AI Hub 다운로드 파일과 라벨 구조
- 모델, API, 화면 기술 스택
- 저장 방식과 시연 환경
- 물리 장비 연동 여부
- 평가 지표와 목표값
