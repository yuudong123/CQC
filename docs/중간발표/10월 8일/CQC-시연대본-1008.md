### 로컬 예시 준비 명령

별도 로컬 터미널에서 발표 전에 실행한다. **품질 연결 모드는 서버 실행 환경**, **물류 모드는 빌드 환경**을 따른다. 단순히 `npm run build`만 해서는 기존 설정과 다른 모드로 바뀌지 않는다.

```powershell
Set-Location -LiteralPath 'C:\CQC\cqc-logistics-platform\apps\web'
$env:CQC_QUALITY_MODE = 'demo'
$env:NEXT_PUBLIC_LOGISTICS_MODE = 'demo'
npm run build
npx next start -p 3201
```

같은 터미널의 환경을 유지해 서버를 실행한다. 다른 터미널에서 실행하면 `CQC_QUALITY_MODE=demo`도 다시 지정한다. 준비가 끝나면 실제로 **브라우저 예시** 배지가 보이고 가상 물류가 표시되는지 확인한다.

**기본 동선의 운영 범위:** 공용 서버에서는 조회·필터·미리보기만 사용한다. 장애 주입, 이력·이미지 삭제, 서버의 발표 상태 초기화는 기본 동선에서 제외한다. 실제 서버의 장애 시험은 담당자가 사전에 합의한 별도 시험 시간과 복구 절차로 수행한다. 조절 UI가 있다는 사실만으로 운영 서버 장애 주입을 실행하지 않는다.

시연 중 새 빌드·배포·공용 서버 재시작으로 복구를 시도하지 않는다.

## 끝나고 확인

- [ ] 로컬 예시의 자동 경매를 일시정지하고 장애 토글을 해제한다.
- [ ] 선택 동선에서 바꾼 로컬 라인 속도를 2초로 돌려놓는다.

## 10-05 갱신 핵심
