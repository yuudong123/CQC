01 · PROBLEM

문제 구조

인력 감소, 육안 판정 편차, 예외 처리 부재가 겹치며 선별 품질과 처리 흐름을 동시에 흔든다.

02 · AS-IS

현행 선별

입고부터 등급 판정, 목적지 선택, 사후 추적까지 사람이 연속해서 맡는 구조다.

입고

물량과 품종이 섞여 들어오고, 선별 대상은 짧은 시간에 집중된다.

육안 확인

작업자가 크기·형태·외관·결점을 동시에 보고 등급을 판단한다.

즉시 결정

애매한 개체도 대기·보류 기준 없이 현장에서 곧바로 등급을 정한다.

수작업 분기

판정 결과를 다시 선별 위치와 연결하면서 전달 오류 가능성이 생긴다.

사후 추적 한계

왜 그 등급이었는지, 어느 구간에서 편차가 커졌는지 되짚기 어렵다.

기준 편차 숙련도, 피로도, 작업 속도, 교대조에 따라 같은 사과가 다르게 해석될 수 있다.
표면 사각지대 한 시점만 보면 반대편·꼭지·배꼽 부위의 결점을 놓치기 쉽다.
전량 동일 처리 명확한 사과와 애매한 사과에 같은 수준의 사람 시간을 투입한다.
피드백 단절 오분류가 쌓여도 등급별·작업 구간별 원인을 데이터로 비교하기 어렵다.

04 · UNIT

판단 단위

한 면이 깨끗하다고
사과 전체가 같은 것은 아니다.

동일한 부사·상 사과를 서로 다른 각도에서 촬영한 예시다. 표면의 색, 꼭지 주변, 배꼽, 반사광이 시점마다 달라진다.

1 여러 각도 확보
개체의 표면 사각지대를 줄인다.
2 하나의 개체로 결합
여러 프레임을 결합해 사과 단위 결과를 만든다.
3 사과 단위로 검증
동일 개체가 학습과 시험에 동시에 들어가는 착시를 막는다.
05 · TO-BE

해결 구조

다각도 입력부터 등급별 목적지와 재검사 분기까지 하나의 흐름으로 연결한다.

다각도 입력동일 사과의 여러 사진을 group_no로 묶는다.
→
통합 판정품종·등급·신뢰도를 사과 한 개 단위로 제시한다.
→
선별 분기정상 목적지와 재검사 상태를 결과 화면에 표시한다.

자동 처리 구간

품종·품질 신뢰도가 기준 이상이고 제한시간 내 응답한 사과 → 6개 정상 목적지 중 하나를 결과값으로 표시

사람 검수 구간

낮은 신뢰도, 처리 지연, 시스템 오류 → 재검사 상태로 표시하고 다각도 이미지를 함께 제시

06 · PLAN

실행 계획

보유 데이터 정리부터 다각도 판정 구성과 자동배차·관제 UI 연결 시연까지 다섯 단계로 진행한다.

1단계 · 데이터 확인

25,024장의 이미지와 JSON 라벨을 확인하고, group_no를 기준으로 동일 사과의 여러 사진을 묶는다.

사과 단위 데이터 구성
2단계 · 판정 범위

판정 대상을 부사·양광과 특·상·보통으로 제한하고, 낮은 신뢰도와 입력 누락 사례를 재검사 조건으로 정리한다.

판정·재검사 조건
3단계 · 다각도 판정

동일 사과의 여러 이미지를 하나의 입력 단위로 사용해 품종, 등급, 판정 신뢰도를 생성하는 흐름을 구성한다.

사과 단위 판정 예시
4단계 · 결과 연계

품질 결과를 품종·등급·수량·샘플 출발지가 포함된 출고 데이터로 변환해 자동배차·관제 UI에 전달한다.

선별–배차 연결 시나리오
5단계 · 통합 시연

준비된 이미지와 샘플 차량 데이터로 품질 판정, 재검사, 출고 물량, 차량 배정, 관제 화면의 연결을 확인한다.

발표용 시연 완성

프로젝트 범위

AI Hub 사과 데이터 활용, 부사·양광 및 특·상·보통 판정, 다각도 종합, 재검사 분기, 출고 데이터 변환, 배차·관제 UI 연결.

시연 범위

자동배차와 배송차량 관제는 샘플 주문·차량 데이터를 사용한다. 실제 로봇팔, 선별 설비, 운송 차량, 농가 현장 연동은 포함하지 않는다.

07 · VALIDATION

검증 지표

보유 데이터와 샘플 시나리오를 기준으로 판정 흐름과 시스템 연결이 계획대로 동작하는지 확인한다.

01 · 품질 데이터 활용품종·등급·수량을 출고와 배송 의사결정의 입력값으로 활용하는 흐름을 제시한다.
02 · 반복 입력 감소선별 결과를 출고 데이터로 자동 변환해 재입력 단계를 줄일 가능성을 보여준다.
03 · 출고 흐름 연결품질 판정 완료부터 차량 배정과 상차까지의 상태 변화를 예시 UI로 연결한다.
04 · 공차거리 계산공차거리는 차량이 화물을 싣지 않고 이동하는 거리다. 샘플 차량별 상차지 이동거리를 계산해 배차 후보를 비교한다.
배차 확정시간선별 완료 후 차량이 결정될 때까지 걸린 시간
공차거리배차 차량이 상차지까지 빈 상태로 이동한 거리
09 · SUMMARY

기획 요약

다각도 사과 데이터를 개체 단위로 묶어 일관된 판정과 선별 분기를 만들고, 품종·등급·수량 정보를 자동배차와 배송차량 관제의 입력값으로 활용한다.

현재 보유한 기반부사·양광, 특·상·보통으로 구성된 25,024장 다각도 이미지와 사과 단위 그룹 정보
검증 가설다각도 종합 판단과 재검사 분리가 판정 편차와 전량 육안 검사의 부담을 줄일 수 있다
