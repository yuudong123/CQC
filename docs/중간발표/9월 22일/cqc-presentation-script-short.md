# CQC 문제 정의 및 해결 계획 — 축약 발표 대본

> 구성: 표지 포함 9개 구간 / 예상 발표 시간: 약 5~6분

## 0. 표지 — CQC 문제 정의 및 해결 계획

안녕하세요. CQC는 사과 두 품종의 다각도 이미지를 활용해 특·상·보통 등급 판정과 재검사 흐름을 설계하고 품질 판정 결과를 자동배차와 배송차량 관제의 입력값으로 연결하는 프로젝트입니다. 이번 발표에서는 사과 선별 과정의 문제, 보유 데이터, 제안하는 업무 흐름, 검증 계획을 설명하겠습니다.

## 1. 문제 구조

2024년 농가인구 중 65세 이상 비율은 55.8%이고, 농가 경영주 중 65세 이상은 69.7%입니다. 농가인구도 전년 대비 4.1% 감소했습니다. 반복 육안 선별의 인력 부담이 커지는 상황이며, 작업자의 숙련도와 피로도에 따른 판정 편차는 재분류와 대기로 이어질 수 있습니다.

## 2. 현행 선별

현재는 입고, 육안 확인, 즉시 등급 결정, 수작업 분기, 사후 확인까지 작업자가 연속해서 담당합니다. 한 방향 관찰에서는 사과 표면의 사각지대가 생기고, 애매한 사례를 보류할 기준과 판정 기록도 부족합니다. 그 결과 같은 사과가 작업자나 시간대에 따라 다르게 분류될 수 있습니다.

## 3. 보유 데이터

저희는 1,000 곱하기 1,000 픽셀 이미지 25,024장과 JSON 라벨을 보유하고 있습니다. 이미지는 224 곱하기 224 픽셀로 리사이즈해서 모델 학습과 예측에 용이하게 가공할 예정입니다. 품종은 부사와 양광, 등급은 특·상·보통이며 실제 사과는 179개입니다. JSON의 `group_no`가 같은 사과의 여러 사진을 연결하고, 품종·등급·크기·중량·촬영 각도 정보도 함께 제공합니다.

## 4. 판단 단위

실제 선별 대상은 사과 한 개이므로 여러 각도 사진을 `group_no`로 묶어 개체 단위로 판정합니다. 각 방향에서 확인한 외관 정보를 결합해 하나의 품종, 등급, 신뢰도를 만들고, 데이터 구분과 평가도 같은 사과가 섞이지 않도록 개체 단위로 진행합니다.

## 5. 해결 구조

제안 흐름은 다각도 입력, 통합 판정, 선별 분기입니다. 신뢰도와 처리시간 기준을 충족한 사과는 품종과 등급에 맞는 목적지 값을 표시하고, 낮은 신뢰도나 입력 누락, 처리 지연, 시스템 오류가 발생한 사과는 재검사 상태로 표시합니다.

## 6. 실행 계획

먼저 이미지와 JSON 라벨을 확인하고 `group_no`를 기준으로 같은 사과의 사진을 묶습니다. 부사·양광과 특·상·보통의 판정 범위와 재검사 조건을 정한 뒤 다각도 판정 흐름을 구성합니다. 판정 결과는 출고 데이터로 변환해 자동배차·관제 UI에 연결하고, 샘플 이미지와 차량 데이터로 전체 흐름을 시연합니다.

## 7. 검증 지표

검증 항목은 개체 단위 결과 생성, 동일 사과의 데이터 중복 방지, 낮은 신뢰도와 입력 누락의 재검사 분기, 판정 JSON의 배차·관제 UI 연결입니다.

## 8. 선별 이후 활용

CQC가 생성한 품종·등급·수량 정보는 출고 물량으로 전환할 수 있습니다. 차량 위치, 잔여 적재량, 기존 경로를 비교해 차량을 배정하고 관제 화면에서 배송 상태를 확인합니다. 이를 통해 반복 입력과 출고 대기를 줄이고, 가까운 차량이나 기존 운행 차량을 활용해 화물을 싣지 않고 이동하는 공차거리를 줄일 가능성을 확인합니다
