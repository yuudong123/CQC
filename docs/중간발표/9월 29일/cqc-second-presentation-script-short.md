# CQC 2차 발표 대본

> 구성: 표지 포함 10페이지 / 예상 발표 시간: 약 6~7분

## 0. 표지 — CQC 개발 계획

안녕하세요. CQC는 사과의 다각도 이미지를 이용해 품종과 외관 품질을 판정하고, 그 결과를 선별과 판매, 자동 배차까지 연결하는 프로젝트입니다. 이번 발표에서는 현재 확정된 개발 범위와 시스템 구성, 데이터 판정 기준, 그리고 남은 통합 작업을 설명하겠습니다.

## 1. 프로젝트 범위

전체 흐름은 다각도 이미지 입력부터 시작합니다. AI가 품종과 외관 품질을 판정하고, 시연용 가상 당도 구간을 결합해 12개 선별 목적지 중 하나를 결정합니다. 선별 결과는 농가 상품 등록과 입찰, 낙찰 주문으로 이어지고, 주문이 확정되면 차량의 적재량과 거리를 기준으로 자동 배차합니다. 실제 결제나 차량 제어, 교통정보 기반 경로 최적화는 이번 범위에 포함하지 않습니다.

## 2. 통합 시스템 구성

품질 선별 영역은 Simulator, Backend, Inference, MySQL, Frontend의 5개 서비스로 구성합니다. Simulator가 동일 사과의 대표 이미지 12장을 입력하면 Backend가 요청과 판정 정책을 관리하고, Inference가 품종과 품질 확률을 반환합니다. 정상 판정 결과는 12개 bin으로 전달되고, 이후 판매·물류 시스템의 상품 등록과 배차 입력으로 사용합니다. 판매·물류 MVP는 로컬에서 구현했으며, QC 전체 서비스와의 통합 실행은 남아 있습니다.

## 3. 기술 스택

데이터와 모델은 Python과 PyTorch를 사용합니다. PyTorch는 사전학습 모델과 이미지 전처리를 활용하기 쉽고, 다각도 입력과 품종·품질 분리 구조를 수정하며 비교하기에 적합해 선택했습니다. 모델은 12장 입력을 CPU 환경에서도 처리할 수 있도록 연산량이 비교적 적은 MobileNetV3 Small을 사용했으며, 현재는 v2 모델을 통합 대상으로 선정했습니다. 백엔드는 FastAPI와 MySQL, 서비스 실행은 Docker Compose와 Jenkins를 사용합니다. 판매·물류 시스템은 Next.js와 FastAPI, MongoDB, WebSocket으로 구성했습니다.

## 4. 데이터와 판정 단위

보유 데이터는 다음과 같고, 저번과 달라진 부분은 가상 당도입니다. 가상 당도는 원본 데이터에 포함된 측정값이 아니라 시연을 위해 별도로 만든 값이며, 사과 이미지 촬영과 동시에 근적외선으로 비파괴 당도 측정하는 설비가 있다는 전제하에 실제 사과의 평균 당도와 표준편차를 반영한 랜덤한 값입니다.

## 5. 12-bin 판정 기준

선별 목적지는 품종 2종, 외관 품질 3등급, 가상 당도 2구간을 결합해 총 12개로 구성합니다. 당도 구간은 12 미만과 12 이상으로 나눕니다. 이미지 입력, 신뢰도, 처리시간과 시스템 상태가 정상일 때 해당 bin을 확정하고, 입력 오류나 낮은 신뢰도, 시간 초과가 발생하면 재검사로 보냅니다. 현재 기본 데이터에서는 12개 조합 중 2개 조합에 표본이 없기 때문에 시연 결과를 해석할 때 이 점도 함께 표시합니다.

## 6. 전체 개발 일정

전체 일정은 9월 16일부터 10월 16일까지이며, 현재는 M3 핵심 기능 개발 구간입니다. M3에서는 모델과 검사 기능, 대시보드의 핵심 기능을 준비합니다. 다음 M4에서는 QC 5개 서비스와 판매·물류 3개 서비스를 연결하고, 이후 성능과 장애 상황을 검증합니다. 기존 WBS 일정은 유지하되, 이후 추가된 12-bin과 물류 작업은 최신 계약과 별도 구현 순서에 맞춰 관리합니다.

## 7. 팀원별 역할 분담

조현재는 데이터 분리와 v2 모델 평가, 가상 당도와 12-bin 계약을 담당합니다. 강성민은 검사 상태와 이력, 통계 화면을 담당하고, 홍준희는 검사 흐름과 데이터베이스, 판정 정책과 가상 제어를 담당합니다. 홍유나는 공통 실행 환경과 CI/CD, CPU 수용시험을 담당합니다. 판매·물류의 세부 담당은 별도로 확정하지 않았으며, 기존 역할에 따라 데이터 계약과 API, 화면, 통합 부분을 나눠 검토합니다.

## 8. 검증 기준과 현재 결과

데이터는 `group_no` 기준으로 분리해 동일 사과의 교차가 없도록 확인했습니다. 통합 대상으로 선정한 v2의 외관 품질 Macro F1은 0.8844로 목표인 0.90에 조금 못 미칩니다. v3 복합등급 모델은 0.6283으로 더 낮아 배차 기준에서 제외했습니다. 가상 당도는 10.7에서 17.9 범위로 생성했지만 실제 측정값은 아닙니다. 목표 장비인 i7-4790에서는 모델 단독 시험과 Inference HTTP, Backend에서 Inference까지의 Compose 경로를 확인했습니다. 전체 경로의 p95는 205.76밀리초로 500밀리초 기준을 충족했지만, 고정 합성 이미지를 사용한 결과이므로 전체 서비스 검증과는 구분합니다.

## 9. 현재 상태와 다음 통합

현재 데이터·모델 파트는 v2 선정과 가상 당도 생성을 완료했고, 백엔드는 12-bin mock 경로와 로컬 시험 98건을 확인했습니다. i7-4790에서는 모델과 실제 Inference, Backend-Inference Compose 경로까지 실행했습니다. 판매·물류는 상품 등록부터 입찰, 배차와 관제까지 로컬 MVP 흐름을 구현했습니다. 다음 단계에서는 DB와 Simulator, QC 화면을 포함한 8개 서비스를 연결하고, QC 판정 결과가 판매와 배차까지 전달되는 5분 시연을 리허설할 계획입니다.
