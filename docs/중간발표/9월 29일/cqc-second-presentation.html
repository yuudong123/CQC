08 · VALIDATION

검증 기준

동일 사과가 여러 세트에 포함되지 않음

품질 성능Macro F1 ≥ 0.90

품종·등급별 Precision·Recall·F1 공개

신뢰도0.50 / 0.50

자동 처리율과 오분류율을 함께 확인

INFERENCEHTTP ≤ 500ms

요청 전송부터 응답 전체 수신까지

처리량≥ 2 그룹/초

CPU Docker 환경에서 연속 요청 측정

서비스정상 100건 + 장애 5종

복구·보존·CSV·상태 표시까지 확인
