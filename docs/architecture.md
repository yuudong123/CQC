# 아키텍처 초안

상태: PPTX 서식 원본 미발견. 슬라이드 구성/필수 항목 분석은 확보 후 진행합니다. 프레임워크와 배포 방식은 미정입니다.

사용자 이미지 입력 → 입력 검증 → 사과 등급 모델 추론 → 신뢰도 판단 → 선별 목적지 결정/시뮬레이션 → 결과 표시·이력 기록

학습 경로: AI Hub 원본(data/raw) → 라벨 분석/분할 → 전처리(data/processed) → 기준선 학습 → 평가 → 모델 파일(models)

## 경계
- AI 판단: 이미지에서 특/상/보통을 예측.
- 자동화: 예측을 검수 큐 또는 등급별 선별 신호에 연결.
- 물리 컨베이어 제어와 DB는 팀의 시연 환경 확인 전까지 미확정.
- API/웹 UI 폴더는 인터페이스 후보를 위한 자리이며 기술 스택 확정 의미가 아닙니다.
