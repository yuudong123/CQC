## 결과

원본 Training·Validation 179그룹을 합친 뒤 품종×품질 조합을 유지하면서 새 Train·Validation·Test로 나눴다.

| 분할 | 그룹 | 그룹 비율 | 프레임 |
|---|---:|---:|---:|
| Train | 125 | 69.8324% | 17,095 |
| Validation | 27 | 15.0838% | 3,918 |
| Test | 27 | 15.0838% | 4,011 |
| 합계 | 179 | 100% | 25,024 |

그룹 크기가 8장부터 184장까지 다르므로 프레임 비율은 정확히 70/15/15가 아니다. 데이터 누수를 막기 위해 프레임 수가 아닌 그룹 수와 품종×품질 조합을 분할 기준으로 사용했다.

## 5-Fold Group CV

최종 Test 27그룹은 모델·입력 장수·신뢰도 기준 선택에서 제외하고 `cv_fold`를 비워 뒀다. Train·Validation 152그룹에만 품종×품질 층화 5-Fold를 적용했다.

| Fold | 그룹 |
|---|---:|
| 0 | 31 |
| 1 | 31 |
| 2 | 30 |
| 3 | 30 |
| 4 | 30 |

- 모든 품종×품질 조합이 다섯 fold에 존재한다.
- 조합별 fold 그룹 수 차이는 최대 1개다.
- 전체 fold 그룹 수 차이도 최대 1개다.
- Train·Validation·Test 사이 `group_no` 교차는 0건이다.
- SHA-256 중복 5쌍은 각각 같은 `group_no` 안에 있으므로 분할 간 누수를 만들지 않는다.

## 재생성

먼저 프레임 매니페스트를 만든 뒤 그룹 분할을 생성한다.

```powershell
python -m src.data.manifest
python -m src.data.split_groups
```

## 리뷰 파일

1. `configs/splits/seed-42.csv`
   - 179개 `group_no`의 최종 분할과 `cv_fold`를 확인한다.
2. `configs/splits/seed-42-summary.json`
   - 전체·조합별 그룹 수, 프레임 수, fold 균형과 원본 분할 이동을 확인한다.
3. `src/data/split_groups.py`
   - 전역 70/15/15 목표와 조합별 층화를 함께 맞추는 생성 로직을 확인한다.
4. `tests/test_split_groups.py`
   - 재현성, seed 변화, 그룹 중복 방지와 fold 균형 테스트를 확인한다.
