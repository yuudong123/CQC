## 확정 사항

- 프로젝트명: CQC
- 프로젝트 기간: 1개월
- 현재 데이터: 사과 이미지
- MVP: 사과 품종 2종
- 확장 한도: 전체 농산물 최대 2개 품목
- 품질 등급: 특·상·보통
- 데이터베이스: MySQL
- DB 목적: 검사 이력 저장과 웹 통계·분석
- 데이터 분석·모델: 조현재
- 프론트엔드: 강성민
- 백엔드·DB 설계: 홍준희
- MLOps·CI/CD: 홍유나

## 아직 결정할 수 없는 항목

- 사과 품종명 2종
- 두 번째 농산물 품목
- 모델·프론트·백엔드 세부 프레임워크
- MySQL 물리 구조와 이미지 보관 방식
- 저신뢰 임계값과 정량 성능 목표
- 정확한 프로젝트 날짜와 발표일
- 물리 선별 장비 연동 여부

미결정 항목은 담당자의 실제 조사·구현 결과 없이 확정값으로 작성하지 않는다.
