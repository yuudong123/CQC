# 서식 확인 및 작성 순서

요청된 서식 4종은 현재 C:\NongProject, 사용자 Documents/Downloads/Desktop 및 사용자 폴더 탐색에서 발견되지 않았습니다. 복사본 생성과 시트·슬라이드 분석은 원본 확보 후 진행합니다. 원본을 직접 수정하지 않습니다.

| 서식 | 원본 | 복사본 | 구조/필수 항목 | 작성 |
|---|---|---|---|---|
| (서식)프로젝트 요구사항.xlsx | 미발견 | 대기 | 대기 | Markdown 초안 |
| (서식)테이블(데이터) 명세서.xlsx | 미발견 | 대기 | 대기 | Markdown 초안 |
| (서식)아키텍처.pptx | 미발견 | 대기 | 대기 | Markdown 초안 |
| (서식)WBS.xlsx | 미발견 | 대기 | 대기 | Markdown 초안 |

서식이 확보되면 원본 보존 → 복사본 생성 → 모든 시트/슬라이드와 필수 항목 파악 → 프로젝트 요구사항 → 데이터/테이블 명세 → 아키텍처 → WBS 순서로 반영합니다. 팀원 인원/역할·기술 스택은 승인 전 TODO로 둡니다.
