# 아키텍처

## 문서 상태
초안. 기술 스택은 미정입니다.

## 처리 흐름
이미지 입력 → 백엔드 입력 검증 → 품질 등급 추론 → 신뢰도 판정 → 선별 목적지 결정 → MySQL 검사 이력 저장 → 웹 결과·이력·통계 표시

## 학습 흐름
AI Hub 원본 → 라벨 검증 → 데이터 분할 및 전처리 → 모델 학습 → 평가 → 모델 저장

## 구성 후보
- 데이터 처리 영역
- 모델 학습 영역
- 추론 영역
- API 영역
- 웹 화면 영역
- MySQL 검사 이력 저장 영역
- 이력·통계·분석 API 영역
