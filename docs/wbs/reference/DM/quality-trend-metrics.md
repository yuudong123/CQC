# 품질 추세 통계 지표 (제안)

- 작성: 조현재 (DM), 2026-10-01
- 상태: **제안** (BE·FE와 범위 합의 전, 기능 동결 10-13 전 여유가 있을 때 진행)
- 배경: 10-01 멘토링(정선교) — 정상·불량 판정 데이터를 DB에 쌓아 일·주·월 단위로 분석하면 농가가 경험이 아니라 데이터로 재배를 개선할 수 있다.

## 1. 지표

우리 데이터의 정답은 특·상·보통이고 "불량" 라벨이 없다. 그래서 불량률 대신 아래 지표를 품질 추세로 쓴다.

| 지표 | 정의 | 비고 |
|---|---|---|
| 등급 분포 | 통계 포함 검사 중 특·상·보통 비율 | 품종별로 나눈다 |
| 상위 등급 비율 | 특 / 통계 포함 검사 | 농가 품질 개선의 핵심 지표 |
| 재검사율(저신뢰) | 품종·품질 저신뢰·가상 당도 누락 / 전체 | 판정 기준 밖 사과가 많아지면 오른다 |
| 시스템 오류율 | 시간 초과·추론 오류 / 전체 | 품질이 아니라 운영 지표로 따로 본다 |
| 당도 구간 비율 | 14°Brix 이상 / 통계 포함 검사 | 가상 값, 화면에 비실측 표시 필수 |
| 평균 추론 시간 | 통계 포함 검사의 평균 | 운영 지표 |

- 통계 포함 규칙은 지금과 같다(FR-28: 시간 초과·시스템 오류만 품종·품질 집계에서 제외).
- 기간 단위: 일(KST 0시 기준), 주(KST 월요일 시작), 월.

## 2. 데이터 보존 제약

검사 이력은 86,400건 순환 보존이다(FR-30). 현재 입력 속도(초당 0.5건)면 약 48시간만 남아 주·월 분석이 불가능하다. 이력과 별개로 **일별 요약 테이블**이 필요하다.

| 컬럼 | 설명 |
|---|---|
| `date_kst`, `cultivar` | 기본 키 |
| `total`, `excluded` | 전체, 통계 제외 |
| `grade_l`, `grade_m`, `grade_s` | 등급별 건수(통계 포함만) |
| `low_confidence`, `brix_missing`, `system_error` | 재검사 사유별 건수 |
| `brix_sweet`, `brix_less_sweet` | 가상 당도 구간 건수 |
| `inference_ms_sum`, `inference_count` | 평균 추론 시간 계산용 |
| `updated_at` | 마지막 반영 시각 |

갱신 방법은 BE가 정한다(검사 저장 시 upsert, 또는 순환 삭제 직전 집계).

## 3. API·화면 제안

- `GET /v1/quality/trends?unit=day|week|month&from=&to=&variety=` → 기간별 `{period, total, grades, highGradeRatio, reinspectionRate, errorRate}` 목록
- 기간 통계 창에 추세 그래프: 등급 비율 100% 누적 막대 + 재검사율 선, 같은 데이터의 표와 CSV
- 시연에서 하루 이상 데이터가 없으면 과거 날짜 예시 데이터를 넣을지 결정이 필요하다. 넣으면 화면과 CSV에 "예시 데이터"로 표시한다.
