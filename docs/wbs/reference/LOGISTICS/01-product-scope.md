# 제품 범위

## 문제 정의

CQC가 농산물의 품종·등급을 판정해도 판매와 운송은 별도 과정이다. 수량·농가·위치는 출품 정보로 입력받고, CQC 결과부터 B2B 구매처 낙찰, 차량 배차, 배송 완료까지 연결한다.

## 사용자

| 사용자 | 할 일 |
|---|---|
| 농가 | CQC 결과 확인, 출품, 최저가 설정, 상차 완료 확인 |
| B2B 구매자 | 출품 검색, 입찰, 낙찰 확인, 하차 완료 확인 |
| 관제 관리자 | 차량·노선·경매·장애 상태 모니터링, 데모 제어 |

## 핵심 사용자 스토리

1. 농가는 CQC 판정 결과를 불러와 최저가를 정하고 출품한다.
2. 구매자는 제한시간 안에 입찰하고 최고 유효 입찰자가 낙찰받는다.
3. 시스템은 적재 가능한 유휴 차량 중 픽업 위치까지 거리가 가까운 차량을 우선 선택한다.
4. 유휴 후보가 없으면 적재 여유가 있는 운행 차량에 정해진 위치로 경유지를 추가한다. 시간창 최적화는 구현하지 않는다.
5. 농가와 구매처의 확인 버튼이 있어야 차량 상태가 다음 단계로 바뀐다.
6. 차량 고장 시 미완료 화물을 인근 가용 차량로 옮겨 새 노선을 만든다.

## MVP 기능

| ID | 기능 | 완료 기준 |
|---|---|---|
| M-01 | CQC 결과 수신 | 품목·등급·수량·농가 위치가 출품 초안으로 생성됨 |
| M-02 | 최저가 설정 | 농가 직접 입력 또는 mock 추천가 선택 가능 |
| M-03 | 실시간 입찰 | 최고가가 WebSocket으로 즉시 갱신됨 |
| M-04 | 낙찰 | 종료 시 최고 유효가로 주문 생성 |
| M-05 | 자동배차 | 용량·상태·거리 조건으로 차량 1대가 자동 선택됨 |
| M-06 | 동적 경유지 | 운행 차량에 신규 픽업·하차 지점 삽입 후 노선 버전 증가 |
| M-07 | 상·하차 확인 | 확인 전에는 다음 운행 단계로 진행되지 않음 |
| M-08 | GPS 시뮬레이션 | 2초마다 차량 위치와 진행률이 갱신됨 |
| M-09 | 대체배차 | 차량 고장 시 새 차량·노선과 알림이 생성됨 |
| M-10 | 통합 관제 | 지도에서 차량, 노선, 주문, 장애를 확인 가능 |

## 후순위

- 실제 도매시장 시세 API 또는 크롤러
- 실제 결제·정산
- 배송 취소·부분 환불
- 냉장 온도 센서
- 교통량 기반 ETA
- 실제 차량 또는 관제 장치 연동
- 복잡한 VRP 최적화 엔진

## 성공 지표

- 데모 1건이 CQC 결과 수신부터 배송 완료까지 끊김 없이 진행된다.
- 신규 주문 발생 후 3초 안에 차량과 노선이 정해진다.
- 적재 한도를 초과하는 배차가 0건이다.
- 고장 이벤트 후 5초 안에 대체배차 결과가 화면에 표시된다.
