# [DM-04] 다각도 로더·누락 뷰 마스킹

## 1. 작업 목적

같은 사과의 여러 각도 이미지를 하나의 모델 입력으로 제공하고, 4·8·12·16·40장 실험을 같은 규칙으로 재현하는 다각도 그룹 로더를 만든다. 40장보다 적은 8·16·21·30장 그룹도 삭제하지 않고 마스크로 처리한다.

## 2. 구현 내용

`src/data/multiview.py`에 다음 기능을 구현했다.

1. 프레임 매니페스트와 고정 그룹 분할을 연결한다.
2. `group_no` 하나를 데이터셋 항목 하나로 구성한다.
3. 각도 메타데이터로 프레임 순서를 결정한다.
4. 4·8·12·16·40장 목표에 맞춰 균등 간격으로 프레임을 선택한다.
5. 부족한 위치에는 `None`과 `view_mask=False`를 반환한다.
6. 선택된 이미지를 원본 ZIP에서 지연 로딩한다.
7. 고정 Train·Validation·Test와 5-Fold CV 로딩을 모두 지원한다.
8. CV 로딩에서 최종 Test 그룹이 포함되지 않도록 차단한다.

실행 명령:

```powershell
python -m src.data.multiview --smoke-load
```

## 3. 프레임 선택 규칙

프레임을 다음 순서로 정렬한다.

```text
angle_direction
→ horizontality_angle
→ verticality_angle
→ sample_id
```

정렬된 프레임 전체 범위에서 첫 프레임과 마지막 프레임을 포함하는 균등 인덱스를 선택한다. 매니페스트 행 순서가 바뀌어도 같은 그룹에서는 같은 프레임이 선택된다.

## 4. 누락 뷰 처리

목표 장수보다 보유 프레임이 적으면 실제 프레임을 모두 유지하고 오른쪽에 패딩한다.

예를 들어 8장 그룹을 40장 설정으로 읽으면 다음 구조가 된다.

```text
images    = [실제 이미지 × 8, None × 32]
view_mask = [True × 8, False × 32]
```

모델의 그룹 결합 계층은 `False` 위치를 평균·attention·pooling 계산에서 제외해야 한다.

## 5. 전체 데이터 검증 결과

| 목표 장수 | 패딩 그룹 | 패딩 슬롯 | 실제 프레임 분포 |
|---:|---:|---:|---|
| 4 | 0 | 0 | 4장 × 179그룹 |
| 8 | 0 | 0 | 8장 × 179그룹 |
| 12 | 1 | 4 | 8장 × 1, 12장 × 178 |
| 16 | 1 | 8 | 8장 × 1, 16장 × 178 |
| 40 | 4 | 85 | 8·16·21·30장 각 1, 40장 × 175 |

## 6. 로더 반환 계약

`MultiViewDataset[index]`는 사과 하나에 대해 다음 값을 반환한다.

- `group_no`
- `cultivar`, `cultivar_index`
- `quality_grade`, `quality_index`
- `split`, `cv_fold`
- `images`: 이미지 bytes 또는 패딩 `None`
- `view_mask`: 실제 이미지 여부
- `angles`: 방향·수직각·수평각
- `sample_ids`: 선택된 원본 프레임 ID

현재 로더는 모델 프레임워크에 종속되지 않도록 이미지 bytes를 반환한다. 이미지 디코딩·리사이즈·정규화와 텐서 변환은 DM-05에서 학습 프레임워크와 함께 연결한다.

## 7. 주요 설계 결정과 이유

### 프레임 선택과 이미지 디코딩을 분리한다

입력 장수·각도 선택·마스크 규칙은 PyTorch 같은 특정 프레임워크와 무관하다. 공통 선택기를 먼저 고정하면 학습과 서비스 Inference가 같은 프레임 선택 규칙을 재사용할 수 있다.

### 이미지 bytes를 지연 로딩한다

25,024장을 미리 메모리에 올리지 않고 실제 데이터셋 항목을 요청할 때 선택된 ZIP 멤버만 읽는다. 사용한 ZIP 핸들은 데이터셋이 닫힐 때 함께 닫는다.

### 패딩 위치는 `None`으로 명시한다

실제 이미지를 반복 복제하면 같은 시점의 특징이 여러 번 반영되어 그룹 표현이 왜곡될 수 있다. 빈 위치를 마스크로 제외하면 보유 프레임만 모델 집계에 사용된다.

### Test 누수를 코드에서 차단한다

CV 역할과 고정 split 필터를 동시에 사용할 수 없게 하고, CV 데이터셋을 만들 때 `split=test` 그룹을 항상 제외한다.

## 10. 다른 파트에 전달할 계약

- 한 요청은 사과 그룹 하나를 나타낸다.
- 이미지 배열은 가변 길이로 받을 수 있다.
- 모델 입력 장수는 4·8·12·16·40장 중 실험으로 결정한다.
- 40장 미만 입력은 오류가 아니라 정상 마스크 입력이다.
- `group_no`와 정답 품종·품질은 모델 특징으로 전달하지 않는다.
- Inference 응답에는 실제 사용 프레임 수와 전처리 버전을 기록한다.
