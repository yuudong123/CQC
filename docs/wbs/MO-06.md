# MO-06 i7-4790 CPU 성능시험 환경

## 1. 작업 개요

- WBS: MO-06
- 담당: 홍유나
- 상태: 부분 완료
- 목적: 고정된 모델 패키지와 12장 입력으로 Inference HTTP 경로를 반복 측정하고, 이후 입력 장수·병렬 수 비교의 기준을 만든다.

## 2. 현재 고정 조건

- CPU: Intel Core i7-4790
- 실행 장치: CPU Docker 컨테이너
- 모델: `cqc-apple-separate12-focal-v2-candidate`
- 입력: 결정적 합성 JPEG 12장, 224×224, 약 302,683 bytes
- 반복: warmup 10회 후 100회
- 지표: HTTP 전체 응답 평균·최대·p95, 서버 model forward 평균·최대·p95, 처리량

## 3. 측정 결과

| 경로 | HTTP 평균 | HTTP p95 | HTTP 최대 | 처리량 |
|---|---:|---:|---:|---:|
| Inference 단독 | 161.90 ms | 198.76 ms | 293.11 ms | 6.18/s |
| Backend → Inference 통합 | 166.61 ms | 205.76 ms | 235.42 ms | 6.00/s |
| 별도 Backend·Inference 프로세스 | 182.85 ms | 244.07 ms | 291.96 ms | 5.47/s |

위 결과는 고정 합성 입력을 사용한 기준선이다. 품질 평가나 실제 생산 이미지 대표성은 이 문서의 완료 기준에 포함하지 않는다.

## 4. 재현 방법

기준 절차와 모델 준비 조건은 [i7-4790 수용 기준](reference/DM/i7-4790-acceptance.md)에 기록했다. Compose 통합 결과 원본은 다음 JSON으로 보존한다.

- [Inference 단독 결과](reference/DM/results/i7-4790-inference-http-20260923.json)
- [Backend·Inference 통합 결과](reference/DM/results/i7-4790-compose-backend-inference-http-20260923.json)
- [별도 프로세스 결과](reference/DM/results/i7-4790-backend-inference-http-20260923.json)

## 5. 남은 작업

MO-06 완료를 위해 같은 Compose 환경에서 4·8·12·16·40장 입력과 순차·병렬 처리 수를 같은 반복 조건으로 측정한다. 결과를 비교해 Backend 동시 처리 수와 500ms 기준 충족 여부를 확정한 뒤 DM-08과 MO-07에 전달한다.
