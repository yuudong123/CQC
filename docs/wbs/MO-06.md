# MO-06 서버컴 CPU 성능시험 환경

## 1. 작업 개요

- WBS: MO-06
- 담당: 홍유나
- 상태: 완료(2026-10-06 완료 기준 변경)
- 목적: 고정된 모델 패키지와 12장 입력으로 Inference HTTP 경로를 반복 측정하고, 병렬 수 비교의 기준을 만든다.

## 2. 현재 고정 조건

- CPU: 서버컴
- 실행 장치: CPU Docker 컨테이너
- 모델: `cqc-apple-separate12-focal-v2-candidate`
- 입력: 결정적 합성 JPEG 12장, 224×224, 약 302,683 bytes
- 반복: warmup 10회 후 100회
- 지표: HTTP 전체 응답 평균·최대·p95, 서버 model forward 평균·최대·p95, 처리량

## 3. 측정 결과

| 경로 | HTTP 평균 | HTTP p95 | HTTP 최대 | 처리량 |
|---|---:|---:|---:|---:|
| Inference 단독 | 161.90 ms | 198.76 ms | 293.11 ms | 6.18/s |
| Backend → Inference 통합 | 166.61 ms | 205.76 ms | 235.42 ms | 6.00/s |
| 별도 Backend·Inference 프로세스 | 182.85 ms | 244.07 ms | 291.96 ms | 5.47/s |

위 결과는 고정 합성 입력을 사용한 기준선이다. 품질 평가나 실제 생산 이미지 대표성은 이 문서의 완료 기준에 포함하지 않는다.

## 4. 재현 방법

기준 절차와 모델 준비 조건은 [서버컴 수용 기준](reference/DM/server-acceptance.md)에 기록했다. Compose 통합 결과 원본은 다음 JSON으로 보존한다.

- [Inference 단독 결과](reference/DM/results/server-inference-http-20260923.json)
- [Backend·Inference 통합 결과](reference/DM/results/server-compose-backend-inference-http-20260923.json)
- [별도 프로세스 결과](reference/DM/results/server-backend-inference-http-20260923.json)

## 5. 남은 작업

남은 작업 없음. 2026-10-06 결정으로 완료 기준에서 입력 장수(4·8·12·16·40장) 비교를 뺐다. 모델이 separate 12장으로 확정되어 운영 중이고, 500ms 기준은 라인 간격 기준(#87)으로 바뀌어 장수를 다시 고를 이유가 없다([의사결정 기록](../planning/decision-log.md)).

병렬 수 비교는 선정 모델로 서버컴에서 측정했다.

- 합성 입력 동시 처리 1·2·4: p95 178·254·397ms([서버컴 수용 측정](reference/DM/server-acceptance.md))
- 실제 시연 사진 동시 처리 1·2: 전체 p95 308.8·528.1ms([DM-08](%5BDM-08%5D%20신뢰도·병렬%20처리%20기준.md))

동시 처리 2부터 사진 해제와 모델이 CPU를 나눠 써서 한 건당 시간이 늘어나므로 운영 동시 처리 수는 1로 둔다.
