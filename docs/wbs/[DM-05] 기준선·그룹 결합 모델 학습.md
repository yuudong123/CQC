# [DM-05] 기준선·그룹 결합 모델 학습

## 1. 작업 목적

동일 사과의 다각도 이미지를 하나의 그룹으로 학습하여 부사·양광 품종과 특·상·보통 품질을 함께 예측하는 첫 기준선을 만든다. DM-03의 고정 분할과 DM-04의 프레임 선택·누락 뷰 마스크를 그대로 사용하며, 이후 입력 장수와 모델 구조를 비교할 수 있는 공통 학습 기반을 준비한다.

## 2. 완료 기준

- 동일한 이미지 특징 추출기를 모든 뷰에 공유한다.
- 패딩된 뷰를 그룹 특징 계산에서 제외한다.
- 품종 2클래스와 품질 3클래스 예측값을 함께 반환한다.
- 고정 Train·Validation 분할에서 Accuracy와 Macro F1을 기록한다.
- 품종·품질별 Precision·Recall·F1과 혼동행렬을 저장한다.
- seed, 입력 장수, 전처리, 모델 설정과 체크포인트를 재현 가능하게 기록한다.
- 최종 Test는 모델과 설정 선택에 사용하지 않는다.

## 4. 1차 기준선 구조

### 이미지 특징 추출

- ImageNet 사전학습 MobileNetV3 Small을 첫 기준선으로 사용한다.
- 각 뷰는 같은 인코더 가중치를 공유한다.
- 기본 입력은 224×224 RGB다.
- MobileNetV3 Small은 최종 승인 모델이 아니라 비교 기준이다.

### 그룹 특징 결합

각 뷰 특징을 `[B, V, F]`로 복원한 뒤 `view_mask=True`인 특징만 평균한다. `view_mask=False`인 패딩 이미지는 0 텐서로 구성하지만 평균의 분자와 분모에서 모두 제외한다.

### 멀티태스크 출력

공유 그룹 특징에서 두 개의 선형 헤드로 분기한다.

- 품종 헤드: `fuji`, `yanggwang`
- 품질 헤드: `L`, `M`, `S`

학습 손실은 품종 교차엔트로피와 품질 교차엔트로피의 결합으로 구성할 예정이다. 두 손실의 가중치는 첫 학습 결과를 확인한 뒤 확정한다.

## 5. 전처리와 증강

- 설정·epoch 이력·최적 체크포인트·SHA-256 요약 파일 저장 확인

- 최적 epoch 20 검증 결과: 품종 Accuracy·Macro F1 1.0000, 품질 Accuracy 0.9677·Macro F1 0.9710
- 두 과제 Macro F1 평균 0.9855, 검증 loss 0.2602
- 최적 체크포인트 SHA-256: `fc1b4dc6b180170e87697f14cf502e5126257430174494d0bfd7847bc3fa3ac8`

### 5-fold 검증 결과

| fold | 최적 epoch | 품종 Macro F1 | 품질 Macro F1 | 두 과제 평균 |
|---:|---:|---:|---:|---:|
| 0 | 20 | 1.0000 | 0.9710 | 0.9855 |
| 1 | 17 | 0.9672 | 0.9691 | 0.9682 |
| 2 | 20 | 1.0000 | 0.9351 | 0.9675 |
| 3 | 20 | 1.0000 | 0.8397 | 0.9198 |
| 4 | 5 | 0.9657 | 0.9346 | 0.9502 |
| 평균 ± 표준편차 | - | 0.9866 ± 0.0184 | 0.9299 ± 0.0534 | 0.9582 ± 0.0248 |

품종 Accuracy는 `0.9869 ± 0.0180`, 품질 Accuracy는 `0.9271 ± 0.0552`다. 품질 과제와 fold 3의 편차가 상대적으로 크며 fold 4는 5 epoch 이후 성능이 하락했다. 조기 종료 기준과 품질 클래스별 혼동 검토가 필요하다.

최종 Test는 사용하지 않았다. 입력 장수와 모델 구조 비교 없이 현재 CV 결과를 운영 성능으로 일반화하지 않는다.

로컬과 원격 원본은 모두 25개 파일, 29,959,373,432바이트이며 파일별 크기 목록도 일치한다. 최초 전송 뒤 대용량 학습 ZIP 2개의 중앙 디렉터리 손상을 발견해 해당 파일만 다시 전송했고, 전체 24개 ZIP 열기 검사를 통과했다.

전송 완료 후 원격에서 매니페스트를 재생성하고 실제 이미지 다각도 smoke-load를 확인했다. 다만 실제 기준선 학습과 성능 지표 산출은 아직 남아 있으므로 학습 성공을 주장하지 않는다.

## 9. 남은 작업

1. 입력 장수 4·12·16·40장과 단일·분리 모델을 비교한다.
2. epoch별 변동과 클래스별 혼동행렬을 검토해 조기 종료 기준을 정한다.
3. 비교 결과로 최종 모델을 선택한 뒤 고정 Test를 한 번만 평가한다.

비교 학습 코드는 `src/training/`에 작성 완료했다. 전체 50개 실험은 실행 전 사용자 확인을 받은 뒤 진행한다.

## 10. 다른 파트에 전달할 계약

- 모델 입력은 `[B, V, 3, H, W]` 이미지 텐서와 `[B, V]` 뷰 마스크다.
- 모델 출력은 품종 logits와 품질 logits다.
- 클래스 순서는 품종 `fuji`, `yanggwang`, 품질 `L`, `M`, `S`로 고정한다.
- `group_no`와 정답 라벨은 모델 특징으로 사용하지 않는다.
- 최종 모델 선정 전까지 MobileNetV3 Small 결과를 운영 승인값으로 사용하지 않는다.
