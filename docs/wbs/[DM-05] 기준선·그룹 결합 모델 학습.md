# [DM-05] 기준선·그룹 결합 모델 학습

## 1. 작업 목적

동일 사과의 다각도 이미지를 하나의 그룹으로 학습하여 부사·양광 품종과 특·상·보통 품질을 함께 예측하는 첫 기준선을 만든다. DM-03의 고정 분할과 DM-04의 프레임 선택·누락 뷰 마스크를 그대로 사용하며, 이후 입력 장수와 모델 구조를 비교할 수 있는 공통 학습 기반을 준비한다.

## 2. 완료 기준

- 동일한 이미지 특징 추출기를 모든 뷰에 공유한다.
- 패딩된 뷰를 그룹 특징 계산에서 제외한다.
- 품종 2클래스와 품질 3클래스 예측값을 함께 반환한다.
- 고정 Train·Validation 분할에서 Accuracy와 Macro F1을 기록한다.
- 품종·품질별 Precision·Recall·F1과 혼동행렬을 저장한다.
- seed, 입력 장수, 전처리, 모델 설정과 체크포인트를 재현 가능하게 기록한다.
- 최종 Test는 모델과 설정 선택에 사용하지 않는다.

## 4. 1차 기준선 구조

### 이미지 특징 추출

- ImageNet 사전학습 MobileNetV3 Small을 첫 기준선으로 사용한다.
- 각 뷰는 같은 인코더 가중치를 공유한다.
- 기본 입력은 224×224 RGB다.
- MobileNetV3 Small은 최종 승인 모델이 아니라 비교 기준이다.

### 그룹 특징 결합

각 뷰 특징을 `[B, V, F]`로 복원한 뒤 `view_mask=True`인 특징만 평균한다. `view_mask=False`인 패딩 이미지는 0 텐서로 구성하지만 평균의 분자와 분모에서 모두 제외한다.

### 멀티태스크 출력

공유 그룹 특징에서 두 개의 선형 헤드로 분기한다.

- 품종 헤드: `fuji`, `yanggwang`
- 품질 헤드: `L`, `M`, `S`

학습 손실은 품종 교차엔트로피와 품질 교차엔트로피의 결합으로 구성할 예정이다. 두 손실의 가중치는 첫 학습 결과를 확인한 뒤 확정한다.

## 5. 전처리와 증강

| 구분 | 처리 |

| 공통 | RGB 변환, 224×224 리사이즈, ImageNet 평균·표준편차 정규화 |
| 학습 | 수평 뒤집기, ±8° 회전 |

## 8. 원본 데이터 전송 상태

로컬 원본은 25개 파일, 약 27.9GB다. 첫 SSH 전송이 중단되어 원격에는 현재 7개 파일, 3,081,458,993바이트만 존재한다. 파일 수와 크기를 대조해 미완료 파일을 다시 전송한 뒤 매니페스트를 원격에서 재생성해야 한다.

전송이 완료되기 전에는 실제 학습 성공을 주장하지 않는다.

## 9. 남은 작업

1. 원격 데이터 파일 수와 크기를 로컬 원본과 일치시킨다.
2. 원격에서 매니페스트와 품질 검사 결과를 재생성한다.
3. 학습·검증 DataLoader와 학습 루프를 구현한다.
4. 우선 8장 입력으로 기준선 학습을 실행한다.
5. 품종·품질 Accuracy, Macro F1, 클래스별 지표와 혼동행렬을 저장한다.
6. 과적합과 클래스 불균형을 확인하고 손실 가중치 필요 여부를 결정한다.
7. 재현 설정과 체크포인트 체크섬을 기록한다.

## 10. 다른 파트에 전달할 계약

- 모델 입력은 `[B, V, 3, H, W]` 이미지 텐서와 `[B, V]` 뷰 마스크다.
- 모델 출력은 품종 logits와 품질 logits다.
- 클래스 순서는 품종 `fuji`, `yanggwang`, 품질 `L`, `M`, `S`로 고정한다.
- `group_no`와 정답 라벨은 모델 특징으로 사용하지 않는다.
- 최종 모델 선정 전까지 MobileNetV3 Small 결과를 운영 승인값으로 사용하지 않는다.
