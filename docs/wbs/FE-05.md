# FE-05 API 갱신·집계·기간 통계

확인일: 2026-09-30 · 담당: 강성민

## 현재 상태

FE 구현, 참조 API 검증, 실제 Backend(조회·통계·장애 이미지) 연결 확인 완료. Simulator·검수 API 연결은 BE-07 이후.

## 구현

HTTP polling은 이전 응답 후 1초 간격으로 진행한다. 취소·시간 제한·마지막 결과 유지·연결 끊김 경고를 구현했다. 오늘 KST 집계, 최근 30초 차트, 1/5/10/30분 합계, 날짜 통계·CSV, 평균 추론 시간·재검사 비율·오판 의심 수를 제공한다. 저신뢰는 정상 집계에 포함하고 시간초과/추론 오류는 제외한다.

구현 파일: QualityStatistics.tsx, useQualityConnection.ts, quality-statistics.ts. 기준 위치는 cqc-logistics-platform/apps/web/src이며 components 또는 lib 폴더에 있다.

## 2026-09-30 실제 Backend 연결 확인

집 PC Docker에 MySQL 8.4·Inference(v2 후보)·Backend(`feat/data` `3509329`, `alembic upgrade head` 적용)를 띄우고 웹을 `CQC_QUALITY_MODE=api`로 연결했다. Simulator 대신 시연 묶음을 `POST /v1/inspections`로 보내는 임시 스크립트로 검사를 만들었다(커밋하지 않음).

| 항목 | 결과 |
|---|---|
| snapshot 1초 polling | "서버 관제" 표시, 오늘 저장·재검사·통계 제외·기간 합계가 DB 값과 일치 |
| 검사 이력 | 서버 `snapshotAt` 고정 pagination, 품종 필터 → `variety=부사` 전달·21건 |
| 기간 통계 | 오늘 43건·재검사 15건(34.9%)·평균 추론 56.7ms, 품종·등급·bin 분포 표시 |
| 통계↔이력↔CSV | 같은 시점 463/464건(1건은 조회 사이 신규), CSV UTF-8 BOM |
| 장애 이미지 | Inference 중지로 36장 생성 → 목록·미리보기·개별 삭제(36→35) 확인 |
| 미구현 API | 검수·제어는 capabilities false로 비활성 표시 |

실제 응답으로 확인한 FE 결함 1건을 고쳤다. Backend 신뢰도가 확률×100 부동소수점(`66.10390000000001`)이라 최근 판정 표가 가로로 넘쳤다(980px > 851px). 화면만 소수 첫째 자리로 표시하고 CSV 값은 유지한다(`quality-format.ts`, 시험 추가).
