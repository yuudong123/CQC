# FE-09 발표 흐름 및 동결 준비

확인일: 2026-09-29. 상태: 리허설 준비 완료, 기능 동결 미실시. M5/ALL-04 선행 미완료.

## 현재 예시 리허설

1. `/` 진입: 헤더·푸터 없는 관제, 예시 표시, 기본 입력 ON 확인.
2. 처리 중 카드와 최근 판정, 오늘 집계·30초 추이 설명. 실제 모델 성능이라고 설명하지 않는다.
3. 입력 정지 → 진행 중 요청 완료 → 입력 재개 및 다음 순번 확인.
4. 시연 설정에서 순차/병렬 카드 전환. 실측 병렬 수와 구분.
5. 입력 정지 상태에서 장애 토글·적용 범위 설정 → 재개. 다음1건 자동 소비와 전체 요청 지속 적용을 구분.
6. DB 오류에서 선별 지속·저장 실패·마지막 저장 시점 경고 확인. 해제 후 실패 이력이 복구되지 않는지 확인.
7. 장애 이미지 관리 → 미리보기 → 오판 의심 지정 → 개별/전체 삭제 확인. 이력은 남고 이미지 목록만 제거.
8. 검사 이력 → 필터 → 50/100/200행 페이지 이동 → 목록 새로고침 → CSV. 이미지 다운로드 제외, 예시 보관 범위와 가상 당도 비실측 표시 설명.
9. 모든 장애 해제·관리 창 닫기·입력 ON으로 복귀.

## 2026-10-14 `/tour` 자막·순서 수정

- 전달받은 자막 1~14를 적용하고, 재검사·오류 사과 설명을 선별함 설명 앞으로 옮겼다.
- 관제 → 농가 입찰 시장·사업자 등록 목업 → 구매자 입찰·결제 → 차량 현황·배송 경로 순서다.
- 안내 단계는 14개다. 배송 경로 다음에 →·Space·Enter를 누르면 화면·강조·14/14를 유지한 채 마무리 인사 자막만 표시한다.
- 마무리 인사에서 ←를 누르면 14/14 배송 경로 자막으로 돌아온다. 자동 시연 시작·결제하기 단계는 기존대로 실제 버튼을 눌러 진행한다.
- 각 화면의 첫 단계(1·6·8·13)는 원래 밝기를 유지하고, 같은 화면의 다음 단계부터 하이라이트 바깥에 검정 4% 음영을 적용한다. 자막과 클릭은 가리지 않으며 버튼의 강조 애니메이션과 별도로 음영을 유지한다.
- 음영 검증: 해당 컴포넌트 lint·production build 통과. 로컬 브라우저에서 네 화면의 첫 단계/다음 단계, 음영 상태의 실제 버튼 클릭, 14/14 마무리 유지까지 확인했다.
- 검증: 웹 시험 55/55, lint 오류 0(기존 경고 5), production build 통과. 로컬 production 서버의 예시 데이터·가상 결제 모드로 순서, 실제 버튼 진행, 14/14 마무리와 뒤로 이동을 확인했다.
