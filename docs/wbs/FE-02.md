# FE-02 반응형 무스크롤 대시보드 골격

- 담당: 강성민
- 계획 기간: 09-19~09-23
- 확인일: 2026-09-29
- 선행: FE-01, BE-01
- 상태: 관제 골격·로컬 화면 검증 완료, 실제 배포 환경 검증 대기

## 완료 기준과 구현

품질 검사 `/`를 화면에 띄워 두는 관리자 관제 화면으로 구성했다. 처리 중 사과, 시스템 상태·최근 오류, 최근 판정, 처리 현황을 네 개 패널로 배치한다. 상단에는 운영 요약과 관리 창·입력 제어를 둔다.

- 품질 페이지의 공통 헤더·푸터와 홍보 문구를 제거했다.
- 입찰·차량 관제 페이지의 공통 메뉴에서 품질 검사 탭을 제거했다.
- 페이지 전체는 화면 너비와 높이에 맞추고 가로·세로 스크롤을 만들지 않는다.
- 최근 판정 등 패널 본문과 관리 창은 내부 스크롤을 허용한다.
- 전체 화면에 transform/zoom 축소를 적용하지 않는다. 텍스트·조작 영역과 유동 이미지 영역을 분리한다.
- 처리 중 이미지는 남은 카드 공간에 맞춰 크기를 조정한다. 특정 해상도를 고정 기준으로 사용하지 않는다.
- 작은 화면에서도 네 패널을 유지하며 내부 스크롤로 내용을 확인한다.

## 구현 위치

- `cqc-logistics-platform/apps/web/src/components/QualityViewport.tsx`: 품질 페이지 전용 화면 컨테이너.
- `cqc-logistics-platform/apps/web/src/components/QualityConsole.tsx`: 관제 패널과 관리 창.
- `cqc-logistics-platform/apps/web/src/app/quality-console.css`: 패널 배치, 이미지 크기, 내부 스크롤, 화면 크기별 스타일.
- `cqc-logistics-platform/apps/web/src/components/Dashboard.tsx`: 공통 헤더 표시와 메뉴 구분.

## 검증과 잔여

1920×1080, 1366×768, 1280×720, 1024×768, 390×844에서 페이지 크기와 화면 크기 일치, 네 패널의 화면 내 배치, 전체 transform 없음을 확인했다. 작은 화면에서는 패널 내부 가로·세로 스크롤이 발생할 수 있다.

실제 배포 브라우저와 데이터량을 사용한 장시간 검증은 [FE-08](FE-08.md)에서 수행한다. 지도 변경은 이번 범위에 포함하지 않았다.
