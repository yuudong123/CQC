# FE-06 시스템 상태·DB 경고·장애 제어

## 현재 상태

FE 구현 및 참조 API 검증 완료. 실제 서비스 통합 검증은 남아 있다.

## 구현

Simulator/Inference/Backend/MySQL 상태와 최근 오류, DB 마지막 저장 시점 경고를 표시한다. 추론 시간초과·추론 오류·DB 오류·명령 거부·제어 무응답 5종, 전체/다음1건 설정을 HTTP로 연결했다. NEXT는 참조 서버에서 한 건만 소비한다. demo는 페이지 새로고침, reference는 서버 재시작 시 설정 초기화된다.

구현 파일: QualityConsole.tsx, useQualityConnection.ts, quality-reference.ts. 기준 위치는 cqc-logistics-platform/apps/web/src이며 components 또는 lib 폴더에 있다.
