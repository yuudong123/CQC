# [DM-06] 모델·입력 장수 비교

## 목적

공유 인코더 멀티태스크 모델과 품종·품질 분리 인코더를 4·8·12·16·40장 입력에서 동일한 5-fold 조건으로 비교한다.

## 준비 완료

- `src/training/experiments.py`: 2개 모델 × 5개 입력 장수 × 5-fold, 총 50개 실험
- `src/training/report.py`: 완료율, 평균·표준편차, CSV·PNG 비교자료와 임시 후보 생성
- `src/training/benchmark.py`: Test 미사용 CPU·GPU 평균·최대·p95 측정
- `src/training/package_model.py`: 승인 체크포인트와 클래스·전처리·SHA-256 패키징
- `src/training/final_fit.py`: 선택 모델의 fold별 최고 epoch 중앙값으로 Test 제외 전체 개발 데이터 최종 학습
- 전체 실험 계획은 `--execute`가 없으면 학습하지 않는다.

## 완료 조건

- 50개 실험의 `summary.json`과 `history.json` 존재
- 각 모델·입력 장수 조합에 5개 fold 존재
- 품종·품질 Accuracy·Macro F1 평균과 표준편차 비교
- i7-4790 CPU 평균·최대·p95와 500ms 충족 여부 비교
- 정확도, 처리시간, 운영 복잡도로 최종 후보 1개 선정

## 50개 실험 검증

`src.training.audit`로 설정, 20 epoch 이력, summary, 체크포인트 SHA-256을 검사해 50/50개 실험이 모두 통과했다.

| 모델 | 입력 | 두 과제 Macro F1 평균 ± 표준편차 | 품질 Macro F1 | i7-14700F p95 |
|---|---:|---:|---:|---:|
| joint | 4 | 0.9613 ± 0.0270 | 0.9294 | 12.3ms |
| joint | 8 | 0.9582 ± 0.0248 | 0.9299 | 11.8ms |
| joint | 12 | 0.9513 ± 0.0204 | 0.9092 | 13.6ms |
| joint | 16 | 0.9635 ± 0.0291 | 0.9401 | 27.8ms |
| joint | 40 | 0.6799 ± 0.0832 | 0.5493 | 64.2ms |
| separate | 4 | 0.9712 ± 0.0143 | 0.9424 | 20.0ms |
| separate | 8 | 0.9528 ± 0.0131 | 0.9056 | 38.2ms |
| separate | 12 | **0.9839 ± 0.0163** | **0.9809** | 55.3ms |
| separate | 16 | 0.9707 ± 0.0236 | 0.9480 | 59.7ms |
| separate | 40 | 0.5807 ± 0.1342 | 0.4896 | 123.7ms |

정확도 기준 임시 후보는 `separate/12장`이다. 40장 입력은 두 구조 모두 정확도와 안정성이 크게 낮아 제외 후보로 분류한다.

`separate/12장`의 fold별 최고 epoch는 `20·15·16·19·20`이며 중앙값은 `19`이다. 최종 학습 코드는 이 값을 결과 파일에서 다시 계산하고, `--execute` 없이는 계획만 생성한다.

## 현재 제약

속도 값은 원격 PC의 i7-14700F 예비 측정이며 목표 i7-4790 승인값이 아니다. i7-4790 측정 전에는 후보를 최종 승인하지 않고 Test도 실행하지 않는다.
