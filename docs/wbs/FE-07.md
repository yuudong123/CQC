# FE-07 장애 이미지·오판 의심 관리

확인일: 2026-09-29 · 담당: 강성민

## 현재 상태

FE 구현 및 참조 API 검증 완료. 실제 서비스 통합 검증은 남아 있다.

## 구현

장애 이미지 미리보기·개별/전체 삭제 확인과 서버 요청을 구현했다. 삭제 확인 시 포착한 ID만 전송하여 이후 도착한 이미지를 보호하고 이력을 유지한다. 품종 의심·품질 의심·기타 지정/해제와 집계를 제공한다. 저신뢰를 자동 오판 표시하지 않는다. 이미지 다운로드와 CSV 이미지 필드는 제외한다.

구현 파일: QualityConsole.tsx, QualityHistory.tsx, quality-reference.ts. 기준 위치는 cqc-logistics-platform/apps/web/src이며 components 또는 lib 폴더에 있다.

## 검증과 잔여
