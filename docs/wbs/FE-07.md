# FE-07 장애 이미지·오판 의심 관리

확인일: 2026-09-29 · 담당: 강성민

## 현재 상태

FE 구현 및 참조 API 검증 완료. 실제 서비스 통합 검증은 남아 있다.

## 구현

장애 이미지 미리보기·개별/전체 삭제 확인과 서버 요청을 구현했다. 삭제 확인 시 포착한 ID만 전송하여 이후 도착한 이미지를 보호하고 이력을 유지한다. 품종 의심·품질 의심·기타 지정/해제와 집계를 제공한다. 저신뢰를 자동 오판 표시하지 않는다. 이미지 다운로드와 CSV 이미지 필드는 제외한다.

구현 파일: QualityConsole.tsx, QualityHistory.tsx, quality-reference.ts. 기준 위치는 cqc-logistics-platform/apps/web/src이며 components 또는 lib 폴더에 있다.

자동 시험·브라우저 확인의 범위는 [FE-08](FE-08.md)을 따른다. 남은 조건: 실제 파일 삭제·보존 상한·DB 오판 기록 영속성 검증.

## 2026-09-30 Backend BE-06 계약 대응

장애 이미지 관리 단위를 검사에서 개별 이미지로 분리했다. `/fault-images` 응답의 id로 preview/delete를 처리하고 inspectionId로 오판 의심을 수정한다. snapshot.state.images는 검사 단위로 유지한다. 실제 장수는 retention.images, 삭제 권한은 capabilities.deleteImages를 따른다. 참조 서버와 브라우저 demo도 같은 보존 단위를 사용한다.

자동 시험 33개 통과. 개별 삭제·같은 검사 나머지 사진/이력 보존·100장 순환·Backend OpenAPI 검증을 추가했다. 실제 배포 파일 삭제 통합시험은 남아 있다. 상세는 [API 인계](협업공지/Frontend-관제-API-계약-인계.md)를 따른다.
