# FE-04 처리 중 카드·입력 제어

확인일: 2026-09-29 · 담당: 강성민

## 현재 상태

FE 구현 및 참조 API 검증 완료. 실제 서비스 통합 검증은 남아 있다.

## 구현

처리 중 카드와 기본 입력 ON, 정지 시 기존 작업 완료, 재개, 서버 허용 병렬 수 선택, 임시 이미지 표시 및 만료 처리를 구현했다. API 제어는 expectedRevision을 보내고 충돌·실패를 표시하며 중복 제출을 막는다. 참조 서버는 1/2/4 병렬을 제공한다.

구현 파일: QualityConsole.tsx, useQualityConnection.ts. 기준 위치는 cqc-logistics-platform/apps/web/src이며 components 또는 lib 폴더에 있다.

## 검증과 잔여

자동 시험·브라우저 확인의 범위는 [FE-08](FE-08.md)을 따른다. 남은 조건: 실제 Simulator 입력·위치 복구·병렬 처리·이미지 파일 만료 검증.
