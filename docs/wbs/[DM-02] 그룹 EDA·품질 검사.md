# [DM-02] 그룹 EDA·품질 검사

## 1. 작업 목적

학습 전에 데이터 분포와 파일 무결성을 확인하여 손상·누락·중복 때문에 모델 평가가 왜곡되는 것을 막는 작업이다. 특히 CQC는 프레임 수가 아니라 사과 그룹 단위로 학습·평가하므로 품종×품질별 그룹 수와 그룹당 프레임 수를 함께 조사했다.

## 3. 구현 내용

`src/data/image_quality.py`에 의존 라이브러리 없이 전체 PNG를 스트리밍 검사하는 기능을 구현했다.

검사 항목:

- PNG 시그니처
- IHDR 구조와 해상도
- 모든 PNG 청크 CRC
- ZIP 멤버 CRC
- 파일 전체 SHA-256
- IEND 이후 불필요한 데이터
- 완전 중복 이미지

실행 명령:

```powershell
python -m src.data.image_quality
```

생성 결과:

- `data/processed/image-quality-report.json`

## 4. 주요 설계 결정과 이유

### 전체 파일을 끝까지 읽는다

파일명과 PNG 헤더만 검사하면 이미지 중간이나 마지막 부분의 손상을 놓칠 수 있다. 약 27.9GB의 원본을 모두 스트리밍으로 읽어 PNG 청크 CRC와 ZIP CRC를 함께 검증했다.

### 한 번에 전체 이미지를 메모리에 올리지 않는다

PNG 청크를 최대 1MB 블록으로 읽어 SHA-256과 CRC를 계산했다. 대용량 ZIP을 검사해도 이미지 한 장 전체를 메모리에 보관하지 않는다.

### 완전 중복 이미지를 자동 삭제하지 않는다

SHA-256이 같은 이미지 5쌍·10장을 찾았지만, 서로 다른 각도 라벨이 붙어 있다. 데이터 오류 후보인 것은 확실하지만 어떤 라벨을 유지할지는 육안 검토와 모델 오류 분석이 필요하므로 원본과 매니페스트에서 삭제하지 않았다.

## 6. 수정·생성 파일

- `src/data/image_quality.py`: PNG·ZIP 전체 무결성 검사와 SHA-256 계산

## 7. 다른 파트에 전달할 계약

- 정상 이미지는 학습 입력으로 사용할 수 있다.
- 40장 미만 그룹도 제외하지 않는다.
- 완전 중복 5쌍은 현재 보존하며 향후 제외 시 분할 파일과 모델 카드에 기록한다.
- 운영 중 정상 이미지는 저장하지 않으며, 이번 원본 무결성 검사는 학습 데이터 준비 과정이다.
