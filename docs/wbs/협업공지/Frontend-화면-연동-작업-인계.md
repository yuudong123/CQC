# FE 화면 준비 후 진행할 WBS 협업 작업

기준: [CQC WBS](../../wbs.md). 화면 준비와 실제 API 연동 완료는 구분한다. 현재 품질 화면은 예시 데이터이므로 FE-05 완료로 처리하지 않는다.

## 직접 연결되는 작업

| WBS | 담당 | 선행 조건 | 진행할 협업 작업 |
|---|---|---|---|
| FE-05 실제 API·통계 연동 | FE·BE | FE-02, BE-05 | 완성된 화면에 실제 검사 이력·오늘 통계를 연결하고 1초 갱신을 확인한다. |
| BE-08 실제 inference·DB·프론트 통합 | BE·FE·DM | DM-07, BE-05, FE-05 | 검사 요청부터 실제 추론·DB 저장·화면 표시까지 연결하고 지연 결과 진단 저장을 확인한다. |
| ALL-03 전체 흐름 1차 통합 | 전체 | DM-07, FE-05, BE-08, MO-07 | Simulator → Backend → Inference → DB·제어 → 웹의 전체 흐름을 확인한다. |

## 위 통합 이후 이어지는 작업

| WBS | 담당 | 선행 조건 | 작업 |
|---|---|---|---|
| BE-09 | BE | BE-05, BE-08 | DB 장애 중 선별 지속, 순환 삭제, 동적 bin 적용 검증 |
| BE-10 | BE·FE | BE-06~BE-09 | 정상 100개, 오류·이력 필터·CSV 통합시험 |
| MO-09 | MO·전체 | M4 | 정상·장애·순환 삭제·CSV·healthcheck 최종 수용시험 자동화 |
| ALL-04 | 전체 | M5 | 정상 100개·초당 2개·장애 5종·보존 정책 수용시험 |

데이터 담당에게 FE 완료 때문에 새로 추가되는 독립 작업은 없다. DM-07의 추론 API·모델 패키지를 기준으로 BE-08·ALL-03 통합 확인에 참여한다. 모델 재학습이나 데이터 재생성은 이 인계 범위에 포함하지 않는다.

MO-07은 WBS상 MO-03~MO-06이 선행이며 FE 완료를 기다려야만 시작하는 작업은 아니다. 실제 웹을 통합 배포할 때 FE와 연결한다.
