# FE-03 관리 화면·이력 필터·CSV

확인일: 2026-09-29 · 담당: 강성민

## 현재 상태

FE 구현 및 참조 API 검증 완료. 실제 서비스 통합 검증은 남아 있다.

## 구현

날짜·품종·등급·bin·상태·오류·오판 의심 필터, 50/100/200행 페이지, snapshotAt 기준 목록 고정, 새로고침, 필터 전체 CSV의 HTTP 연결 구현. 오판 의심 지정/해제는 서버 성공 후 반영한다. 날짜 역전·빈 결과·통신 실패를 표시한다. CSV는 이미지 제외, 비실측 표시, 따옴표/수식 문자 보호를 적용한다.

구현 파일: QualityHistory.tsx, quality-api.ts. 기준 위치는 cqc-logistics-platform/apps/web/src이며 components 또는 lib 폴더에 있다.

## 검증과 잔여

자동 시험·브라우저 확인의 범위는 [FE-08](FE-08.md)을 따른다. 남은 조건: 실제 DB 보존 이력과 pagination·필터·CSV 일치 검증.
