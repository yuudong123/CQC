## MySQL 검사 이력

MySQL 사용은 확정되었다. 아래 필드는 기획 단계의 저장 요구사항이며 실제 테이블명, 컬럼명, 타입, 키, 관계, 인덱스와 마이그레이션은 백엔드 담당자가 별도 DB 설계 문서에서 확정한다. 웹의 검사 이력과 통계·분석 기능은 해당 설계를 기준으로 구현한다.

### 저장 요구 필드 후보
| 필드 | 설명 | 상태 |
|---|---|---|
| prediction_id | 판정 ID | 가정 |
| created_at | 판정 시각 | 가정 |
| predicted_grade | 예측 등급 | 가정 |
| confidence | 신뢰도 | 가정 |
