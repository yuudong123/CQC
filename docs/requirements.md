# 프로젝트 요구사항 초안

상태: 서식 원본 미발견. 실제 엑셀 필수 항목은 서식을 확보한 뒤 분석해 매핑할 예정입니다.

## 목적과 범위
사과 이미지의 품질 등급(특/상/보통)을 AI로 예측하고 선별 결과를 자동 기록·표시합니다. 감귤은 확장 후보입니다. 설비보전 기능은 포함하지 않습니다.

## 기능 요구사항
| ID | 내용 | 수용 기준 초안 | 우선순위 |
|---|---|---|---|
| FR-01 | 사용자가 이미지 또는 샘플을 입력한다 | 지원 형식과 오류 안내가 작동한다 | 필수 |
| FR-02 | 선택한 품목의 품질 등급과 신뢰도를 예측한다 | 특/상/보통 결과가 표시된다 | 필수 |
| FR-03 | 예측 등급에 맞는 선별 신호를 생성한다 | 시뮬레이션 로그에서 등급별 목적지를 확인한다 | 필수 |
| FR-04 | 저신뢰 결과를 검수 대상으로 분리한다 | 임계값은 검증셋 분석 후 정한다 | 필수 |
| FR-05 | 판정 이력을 조회한다 | 입력/출력/시간을 재현할 수 있다 | 후보 |

## 비기능·제약
- 데이터 누수 방지: 동일 개체/연속 촬영이 확인되면 분할 단위를 조정합니다.
- 성능 목표, 응답 시간, 운영 환경은 기준선 실험 후 TODO.
- 품질 등급은 AI Hub 라벨 정의를 따르며 실제 상품 거래 등급 보증으로 표현하지 않습니다.
- 사용 허가/다운로드 조건과 데이터 파일 구조는 직접 확인해야 합니다.
