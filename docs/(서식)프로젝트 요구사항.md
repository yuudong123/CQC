# 프로젝트 요구사항

## 문서 상태
초안. 팀 합의가 필요한 항목은 TODO로 표시합니다.

## 목표
사과 이미지의 품질 등급을 AI로 판정하고 결과를 선별 흐름으로 연결합니다.

## 기능 요구사항
- 이미지 입력
- 특·상·보통 등급 및 신뢰도 출력
- 등급별 선별 목적지 생성
- 저신뢰 결과 수동 검수 표시
- 검사 결과와 처리 이력을 MySQL에 저장
- 웹에서 검사 이력 조회
- 웹에서 기간·품목·품종·등급 기준 통계와 분석 조회

## 범위 제외
- 설비 고장예지
- 설비보전
