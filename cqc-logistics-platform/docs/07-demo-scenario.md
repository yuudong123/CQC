# 발표 데모 시나리오

## Seed 데이터

- 농가 2곳: 아산 사과농장, 충주 사과농장
- 구매처 3곳: 서울 마트, 수원 급식센터, 대전 식자재센터
- 차량 3대: 1톤 1대, 2톤 2대
- 기존 운행 노선 1개, 대기 차량 2대
- CQC 결과: 부사 특 500kg, 양광 상 300kg

## 5분 시연

1. CQC가 `부사·특·500kg`을 판정한 결과를 보여준다.
2. 농가 화면에서 추천 최저가를 선택하고 경매를 연다.
3. 구매자 두 명이 입찰하고 관제 화면 최고가가 실시간으로 바뀐다.
4. 경매를 종료해 낙찰 주문을 만든다.
5. 시스템이 차량의 위치·잔여 적재량·추가 거리를 비교해 자동배차한다.
6. 운행 중 두 번째 물량을 발생시켜 기존 노선에 경유지가 추가되는 모습을 보인다.
7. 농가 상차 완료 버튼 후 차량이 다음 지점으로 출발한다.
8. 차량 고장 버튼을 눌러 대체 차량과 알림이 생성되는 모습을 보인다.
9. 구매처 하차 완료 버튼으로 주문을 종료한다.

## 발표 핵심 문장

> CQC의 품질 데이터가 선별에서 끝나지 않고, 판매 의사결정과 차량 배차의 입력 데이터가 되도록 연결했습니다.

> 실제 자율주행 알고리즘을 만든 것이 아니라, 자율주행 화물망이 받아야 할 주문·경로·상하차·예외 관제 명령을 자동화했습니다.

## 실패 대비

- Google Maps 키 실패: 지도 영역 안내 fallback을 보여주고 좌표·차량 목록으로 시연 지속
- WebSocket 실패: 2초 Polling으로 최고가 갱신
- 경로 API 실패: 좌표 간 직선거리와 고정 속도로 ETA 계산
- 시연 데이터 꼬임: seed reset 버튼으로 초기 상태 복구
